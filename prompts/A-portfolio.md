# Prompt A — the portfolio (paste as the first message in Claude Code, in the folder that holds your existing projects)

I am a second-year student at the Technical University of Sofia (computer science, AI, electrical and physical computing). I have held an EU drone pilot licence for aircraft up to 20 kg since I was 17. I am about to email drone and robotics companies, and my GitHub has to prove I exist before I do. You are helping me fix it in two days.
 
First, interview me. Ask, one question at a time:
1. My GitHub username and the three projects I want to pin (paths on disk or repo URLs).
2. For each project: what it does in one sentence, whether it runs today, what hardware it needs, and one image or video I can show.
3. My email, city, and one photo of me with the drone.
4. Anything in my GitHub I am embarrassed by (empty repos, broken forks) that should be deleted or archived.
 
Then, project by project:
- Read the code. Tell me in plain words what it actually does and where it is unfinished. Do not flatter it.
- Write a README with exactly this shape: one sentence saying what it does; one image or GIF; how to run it (commands that work on a clean machine); what I learned; what I would do differently. Where something is unfinished, say "works up to step N, step N+1 is open." Every claim must be true; ask me before writing any number.
- Add a LICENSE (MIT), a .gitignore, and pin dependency versions.
- Do anything that stops the quickstart from running. Ask before large changes.
 
Then write my profile README (github.com/\\\\: one paragraph. What I study, the licence, what I build, and how to reach me. Plain, first person, no adjectives. Add a line "Currently building: an open-source apricot drone with a tap-to-inspect console (link)" with a placeholder link.
 
Rules:
- Sentence case. Short sentences. Say what a thing is, never what it is not.
- Do not invent results, metrics, or features. If you cannot verify something runs, say so and I will run it.
- Commit after each README with a one-sentence message.
- At the end, give me a checklist of what I still have to do by hand (pin repos, upload the photo, delete repos).
