# Prompt B — the apricot drone (paste as the first message in Claude Code, in an empty folder called apricot-drone)

This is a three-week hackathon project. I am building an open-source system that turns a drone into an orchard scout with a human in the loop: it takes off autonomously, surveys a small apricot orchard, photographs every tree, stitches the photos into one map, and shows that map in a web console where a person taps a tree to say "look closer", "spray", or "fine". Level one: grid survey, stitch (OpenDroneMap), find tree crowns (DeepForest or similar), give each tree a persistent id by location, crop each crown, send crops to a vision model behind one interface (image in, JSON out: risk level, disease candidates, confidence, reason, suggested view angle) with two backends from day one: a local open vision model through Ollama, and an optional hosted API, colour the map, list proposals; the person approves or edits with taps. Level two: each approved tree gets an orbit mission (PX4 orbit / ArduPilot circle / DJI POI) at 6–8 m with a photo every 30 degrees; each photo is assigned to a tree from drone position and camera heading; the console shows a tile gallery per tree, tap to open, tap to close; the model re-reads close-ups; a custom YOLO detector is trained on the accumulated taps. Level three makes the spray command execute on whatever sprayer the aircraft has (servo/relay output on PX4/ArduPilot, ArduPilot's sprayer feature, or the vendor SDK on a DJI agricultural aircraft), with the console showing live progress, a stop button, and what was sprayed. The first orchard is my aunt's garden in the Czech Republic; my uncle will fly it there following a one-page pack I write; I am in Sofia. I hold an EU licence for drones up to 20 kg. A partner may build the console as her own piece; treat it as a separate package with a clean interface.

3. How I get the live camera feed and GPS into my own code on that aircraft.

5. The diseases my aunt has seen (brown rot / Monilinia, shot-hole / Stigmina, dieback, or unknown) and whether I have photos.
6. How many trees, how big the plot is, and what is around it.
7. How many days I have and whether I have a GPU.
