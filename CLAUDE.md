# Project guidance

Read README.md for the challenge and WORLD.md for the learning guide. AGENTS.md carries the same rules for other coding tools.

Use clear English and define new terms through examples. Ask one hardware question at a time. Record actual facts in HARDWARE.md and LEGAL.md.

The two-week goal is an orchard survey, galleries, human review and a proposed treatment route. Spraying is a later project. Agree flight scope from the actual aircraft, SDK support, operator, permissions and access dates.

Start with the offline exercise, then one real image. Plan small steps, explain important changes and ask the student to run and inspect them. Ask the student to explain key decisions back. Use measured results, identified sources and clearly labelled sample data. Keep observations, labels, approvals and treatment selections separate.

An offline route is a planning drawing. Flight integration is a distinct reviewed step with appropriate simulation, pilot control and operating permissions. Treat secrets and precise private locations as private data.

Preserve the student's own writing and learning. Help clarify their English. Credit collaborators, models, libraries and datasets. End a session by updating LOG.md with the actual result and next experiment.
