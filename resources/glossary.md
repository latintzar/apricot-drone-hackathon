# Project words

Use this as a reference while building. WORLD.md explains the startup and career terms.

- **Repository / repo:** one project's files and history on GitHub.
- **Git:** the tool that records changes. A **commit** is a saved change with a message.
- **Branch:** a line of changes you can work on separately. A **pull request / PR** asks someone to review and merge changes. A **fork** is your copy of another repo for contributing back. A **template** starts a fresh project from existing files.
- **README:** the project introduction and instructions. **Markdown** is the simple text format used to write it.
- **Open source / licence:** permission to use and change code under stated terms. Data and model weights may have separate terms.
- **Terminal:** a window where you type commands. **Environment:** the installed language and libraries your code uses. A **dependency** is another package your code needs.
- **API / SDK:** an API is an interface for software to talk to software. An SDK is a toolkit for building that connection. Check support for your exact drone.
- **Flight controller:** the aircraft's stabilisation and control computer. **Flight stack:** its software, such as PX4 or ArduPilot.
- **MAVLink:** a message protocol used by flight systems. **Telemetry:** measurements sent back, such as position and battery.
- **Companion computer:** an extra computer connected to the flight controller. Some projects run their image processing on a laptop on the ground.
- **Waypoint / mission:** a waypoint is a target position; a mission describes a planned sequence of actions.
- **Simulation:** testing behaviour in a model of the aircraft or world. **Replay:** processing saved data again. **Field test:** a test using real equipment in its operating setting.
- **Orthomosaic:** overlapping photographs joined into a map-like image with corrected geometry. **Georeference:** the connection from image pixels to locations on Earth.
- **CRS:** coordinate reference system; tells you what coordinates mean. **GPS/GNSS:** satellite positioning systems. **Ground sampling distance / GSD:** the size of ground represented by one pixel.
- **Crown:** the canopy of a tree seen from above. **Detection:** finding objects, often as boxes. **Segmentation:** marking the pixels belonging to an object.
- **Model:** learned rules stored as parameters. **Inference:** running a trained model. **Training:** adjusting it using examples. **Pretrained:** trained before you use it.
- **Annotation / label:** a recorded description or category attached to data. A **prediction** is the model's output. A **checked label** has an identified review process.
- **Training set / test set:** examples used to learn, and separate examples used to assess performance. **Data leakage:** information from the test examples accidentally influences learning.
- **Precision:** among the detections called positive, the fraction that were correct. **Recall:** among the real positives, the fraction found. Report how you checked the labels and how many examples you used.
- **Baseline:** a simple method you compare against. Hand-marked trees or a pretrained detector can give you a first baseline.
- **JSON / CSV:** text formats for structured records or rows. **GeoJSON:** JSON with geographic shapes and coordinates.
- **Console:** the web interface used to review the orchard. **Deployment:** making an app available for someone to use.
