# Instructions for the field helper

Fill one page with the actual aircraft and approved collection steps.

1. Prepare: equipment, charged batteries, storage, approved location and pilot.
2. Collect: the agreed survey or close-up steps, with pilot control throughout.
3. Transfer: where to put the images and flight log, preserving names and timestamps.
4. Check: how to confirm the expected files arrived.
5. Report: what happened, one observation and what needs help.

Watch your helper follow the page and improve it from their questions.
